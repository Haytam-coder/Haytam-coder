# Arbeitszeiterfassung für einen Supermarkt

**Full-Stack-Eigenprojekt** · [Zurück zur Übersicht](../README.md)

## Worum geht es?

Für einen lokalen Supermarkt habe ich ein System gebaut, mit dem Mitarbeitende am Terminal stempeln und die Zeiten direkt digital gespeichert werden.

## Aufbau

- **Backend:** REST-API in Python
- **Frontend:** Web-App in React für Übersicht und Verwaltung
- **Datenbank:** SQL
- **Hardware:** Arduino-Terminal, das die Stempelzeiten direkt an die API sendet

Ich habe das Projekt allein umgesetzt, von der Abstimmung mit dem Inhaber über die Datenbank bis zur Hardware.

## Tech-Stack

Python · React · SQL · REST-API · Arduino
