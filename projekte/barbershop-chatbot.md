# KI-Assistent für einen Barbershop

**Conversational-AI-Demo** · [Zurück zur Übersicht](../README.md)

## Worum geht es?

Ein kleiner Barbershop bekommt jeden Tag dieselben Anrufe: Was kostet ein Haarschnitt? Wann habt ihr offen? Kann ich einen Termin buchen? Der Chatbot beantwortet genau diese Fragen und entlastet so das Team.

## Funktionen

- Beantwortet Fragen zu Preisen, Öffnungszeiten und Terminen
- Quick-Reply-Buttons für die häufigsten Anliegen
- Schlichte Chat-Oberfläche
